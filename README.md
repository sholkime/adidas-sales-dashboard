# adidas-sales-dashboard
# 📊 Adidas Sales Performance Dashboard (Excel)

An interactive and comprehensive Excel Sales Dashboard built to analyze sales performance, revenue trends, and profitability for Adidas products across multiple regions and categories.

---

## 📌 Project Overview
This project visualizes multi-year sales data for Adidas to help business stakeholders uncover sales trends, track key performance indicators (KPIs), and optimize regional distribution strategies. The entire dashboard is fully dynamic and updates instantly based on selected filters (slicers).

## 🚀 Key Features & KPIs

### 1. High-Level Summary Cards (KPIs)
Dynamic KPI cards at the top of the dashboard providing quick insight into overall performance:
* **Total Units Sold:** Real-time cumulative quantity of items sold.
* **Total Profit:** Overall net margin generated.
* **Sales Revenue:** Gross sales generated across all active filters.

---

### 2. Interactive Slicers & Filters
Allows users to slice and drill down into data across various dimensions:
* **Date / Timeline:** Multi-year trend analysis (2023 - 2025).
* **Product Category:** Footwear, Apparel, and Accessories.
* **Region / Country:** Egypt, Iraq, KSA, Lebanon, Oman.
* **Store Type:** Distribution channel segmentation.
* **Gender:** Men vs. Women products.

---

### 3. Visualizations Breakdown

| Section | Visual Type | Description |
| :--- | :--- | :--- |
| **Top Left** | Donut Chart | **Revenue by Category:** Breakdown of sales across Footwear, Apparel, and Accessories. |
| **Bottom Left** | Donut Chart | **Revenue / Profit by Region:** Regional profitability share across Middle East markets. |
| **Center (Top)** | Column Chart | **Revenue Sales by Product:** Product-level performance (e.g., Stan Smith, Adicolor Hoodie, Tiro Pants, etc.). |
| **Center (Bottom)** | Trend Line Chart | **Quarterly Sales Trend:** Sales trajectory quarter-by-quarter across multiple years ($Q1$ to $Q4$). |
| **Top Right** | Horizontal Bar Chart | **Units Sold by Region:** Volume comparison across key territories. |
| **Bottom Right** | Clustered Column Chart | **Revenue Sales by Region:** Comparison of dollar value sales by country. |

## 🖥️ How to Use
1. Clone or download this repository:
   ```bash

   ```
2. Open `Adidas_Sales_Dashboard.xlsx` using **Microsoft Excel 2016** or newer (desktop app recommended for optimal slicer interactivity).
3. Interact with the **Slicers** to filter data by date, country, category, and gender to explore customized views.
